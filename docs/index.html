Supported Embedding Architectures

State-of-the-art architectures optimized for Metal GPU cores and unified RAM

⚡

ModernBERT

Unpadded FlashAttention, GeGLU feed-forward networks, and Rotary Position Embeddings scaling up to 8,192 token context windows.

👁️

SigLIP Vision

Sigmoid loss vision transformers extracting spatial patch tokens and global semantic image vectors for multimodal retrieval.

🎯

ColBERT v2

Token-level multi-vector late interaction via MaxSim operator for superior precision without large cross-encoder latency.

📚

BGE / BERT

Dense text embeddings with customizable CLS, Mean, Max, and Last-Token pooling strategies with L2 unit sphere normalization.

    Command Line Usage

    Fast, scriptable CLI built directly into the native Rust binary

    bash - mlx-embeddings CLI 
    # Generate embeddings with ModernBERT and Mean pooling
mlx-embeddings embed --text "High-speed dense vector embeddings on Apple Silicon" --model modern-bert

# Compute cosine similarity between two sentences
mlx-embeddings similarity -a "Neural search on Metal" -b "Deep learning on Apple GPU"

# Perform top-k semantic search over a collection
mlx-embeddings search --query "Machine learning" --docs "AI research,Cooking recipes,Computer vision" --top-k 2

# Inspect model architecture details
mlx-embeddings info --model col-bert
